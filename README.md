## 🚀 What this repository is

`LaxmanNepal/laxmannepal` is the source for my **public GitHub portfolio and personal showcase dashboard**.

The live site is designed as a dynamic portfolio rather than a static résumé. It can discover public repositories and present repository statistics, languages, commits, activity and project information from GitHub.

### Showcase capabilities

| Capability | Purpose |
|---|---|
| 📊 Portfolio analytics | Stars, forks, repositories, size and language coverage |
| 🗂️ Repository explorer | Searchable/filterable public project catalogue |
| 🧑‍💻 Developer activity | Recent repository activity and commits |
| 📈 Language intelligence | Language composition from repository data |
| 🕒 Timeline | Recent project changes |
| 📖 README viewer | Displays this documentation inside the portfolio |
| 🔗 Ecosystem links | GitHub, apps, website and creator platforms |
| 📱 Responsive UI | Desktop and mobile presentation |

# 🔧 Local development

No build system is required.

```bash
git clone https://github.com/LaxmanNepal/laxmannepal.git
cd laxmannepal
```

Then open `index.html` in a browser or serve the directory with any static web server.

Update:

- `apps.json` → application catalogue
- `youtube.json` → YouTube snapshot data
- `index.html` → portfolio presentation
- `README.md` → profile documentation
