# YouTube Workspace

This folder is the central entry point for YouTube-related planning and creator tools.

## Start here

- **[Workspace homepage](index.html)** — directory of current and planned workspaces.
- **[Content Growth](content-growth/)** — current topic research dashboard, idea backlog, briefing archive, research workflow and script workbench.

## Planned folder structure

Add these only when there is enough material to keep them useful:

- `scripts/` — approved scripts, outlines, narration and reusable templates.
- `research/` — source links, access dates, official references and claim checks.
- `analytics/` — video performance snapshots, CTR, retention and experiments.
- `thumbnails/` — thumbnail concepts and title/packaging tests.
- `published/` — published video index, URLs, dates and follow-up opportunities.
- `strategy/` — channel positioning, content pillars and publishing plans.

## Workflow

1. Collect candidate ideas in `content-growth/topic-backlog.csv`.
2. Research the selected idea and add primary sources plus the date checked.
3. Use the dashboard's Script Workbench to create an editable first draft.
4. Verify all factual claims and test the actual product/tool before recording.
5. Save or download the script, then record publication and performance notes when those workspaces are added.

The dashboard is static HTML/JavaScript and is intended for GitHub Pages. Script draft saving uses the current browser's local storage; it is not synced to GitHub or another device automatically.
